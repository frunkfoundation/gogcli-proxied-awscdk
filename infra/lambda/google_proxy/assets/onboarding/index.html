Sign in as the owner

1. Create or choose a Google Cloud project
  1. Create a Google Cloud project ↗. Sign in with the account that will own this app. Use a recognizable name, such as “Jay Gmail access”.
  2. Select that project in the picker at the top of the console. One project can serve personal Gmail and accounts from different Google Workspace organizations.
  3. Copy its Project ID below to make the next links open your project. This is the ID, not the display name.
2. Enable the Gmail API

Open the Gmail API page ↗, confirm your project, then click Enable. “Manage” means it is already enabled.

3. Set up and publish the Google consent screen
  1. Open Branding ↗. If prompted, click Get started. Enter an app name, support email and developer contact email.
  2. Open Audience ↗. Choose External to allow personal Gmail and different Workspace organizations. “Internal” permits only one organization.
  3. Open Data Access ↗. Click Add or remove scopes, add the three permissions below, then click Update and Save. Enter the full URL manually if a permission is missing.
    • openid
    • email
    • https://www.googleapis.com/auth/gmail.modify
    Gmail permission allows reading and changing mail, including sending. The connection check only reads your profile and at most one message ID.
  4. Return to Audience and click Publish app before connecting accounts. For Gmail, refresh tokens issued while an External app is in Testing expire after seven days. Reconnect any accounts previously connected in Testing.

Publishing changes the audience status; it does not complete Google's app verification. Personally known users may qualify for Google's personal-use exception and see an unverified-app warning. Workspace administrators can restrict access. Google's verification guidance ↗

This is your confirmation. This page cannot independently check Google's publishing status.

4. Create a Web application client and upload its JSON
  1. Open Clients ↗, then click Create client.
  2. Choose Web application, enter a name, and under Authorized redirect URIs click Add URI. Paste this exact address, including its path:

  1. Click Create. Download the client's JSON, then upload it below. A Desktop client will not work for this hosted callback.

The file is uploaded over HTTPS and stored securely on the server. Google credentials and tokens are never saved in this browser's storage or your Mac keychain.

5. Connect each Gmail account

Enter an email, then choose Connect Gmail. Google opens in this tab; choose that exact account and approve access. You return here automatically. The server continues checking even if this page is closed.

“Verified” means a real read through the normal signed proxy passed after the credential cache expired. A mailbox with no messages passes too.
